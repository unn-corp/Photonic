# UNNDEV UI standards: Photonic

Version: 1.0
Adoption scope: new or materially changed UI within the surfaces below, after this change is accepted into the repository. Existing screens are not certified by installing these documents.

## Start here

1. Read the repository’s existing instructions and [local profile](UI-PROFILE.md).
2. Apply [UNNDEV UI Standards Core 1.0](UNNDEV-UI-STANDARDS-CORE.md) within the stated scope.
3. Declare applicable surfaces, component/token owners, relevant rule IDs and verification evidence for each UI change.

## Scope and authority

NATIVE + EDITOR for the desktop GUI; apply TOUCH only where touch is supported and tested. Headless protocol operations are not web UI.

The core supplies common interaction, accessibility and verification outcomes. The local profile preserves this product’s visual identity, platform rules and approved local constraints. Existing repository safety, architecture, contribution and release requirements remain in force. Escalate contradictions rather than silently weakening either source. This adoption does not authorize redesign, package publication, merge or deployment.
