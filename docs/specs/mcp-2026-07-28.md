## 1. Deployment model

| Path | Use |
|------|-----|
| **MCPB** (`.mcpb` binary bundle) | Preferred install for desktop hosts that must run on-machine |
| **Streamable HTTP** `POST /mcp` on loopback | GUI attach, AS scripts, multi-client |
| **stdio** Content-Length | MCPB spawn / Inspector (`--mcp-stdio`) |
| Remote OAuth cloud MCP | **Out of scope** |

```
Host (Claude Desktop / agent)
  ├─ MCPB: spawn photonic --mcp-stdio
  ├─ Proxy attach: photonic mcp-proxy → HTTP :7842 + Bearer
  └─ Direct HTTP: POST http://127.0.0.1:7842/mcp
```

## 2. Protocol

### 2.1 Versions

| Mode | Flag | Behavior |
|------|------|----------|
| **dual** (default) | `--mcp-protocol dual` | Accepts `2026-07-28` and legacy `initialize` / bare calls |
| **strict** | `--mcp-protocol strict` | `2026-07-28` only; requires `_meta` + `Mcp-Method` |

Constants live in `crates/photonic-mcp/src/protocol/envelope.rs`.

### 2.2 Methods

| Method | Notes |
|--------|--------|
| `server/discover` | **MUST** — versions, tools capability, `resultType`, `ttlMs`, serverInfo |
| `tools/list` | Compact by default; `params.full: true` or `PHOTONIC_MCP_FULL_TOOLS=1` for full catalog |
| `tools/call` | Result wrapped with `resultType: "complete"` |
| `initialize` / `notifications/initialized` | Dual only |

### 2.3 Per-request `_meta` (2026 clients)

```json
"_meta": {
  "io.modelcontextprotocol/protocolVersion": "2026-07-28",
  "io.modelcontextprotocol/clientCapabilities": {},
  "io.modelcontextprotocol/clientInfo": { "name": "my-client", "version": "1.0.0" }
}
```

### 2.4 HTTP headers

| Header | Dual | Strict |
|--------|------|--------|
| `Mcp-Method` | Optional; must match body if present | Required |
| `Mcp-Name` | Optional for `tools/call` | Required for `tools/call` |
| `Authorization: Bearer <token>` | Required when secret configured | Same |

Mismatch → JSON-RPC **`-32020`**. Unsupported version → **`-32022`**.

### 2.5 Body limit

Default **8 MiB** (`DefaultBodyLimit` on the router).

## 3. Authentication

- Loopback bind only (`127.0.0.1`).
- **No CORS** layer.
- Session token: generated at launch if `--mcp-secret` omitted; written to app config `mcp_token` (`0o600` on unix).
- Env override for clients: `PHOTONIC_MCP_TOKEN`.
- Unauthenticated HTTP → bare **401**, empty body.

Code: `crates/photonic-mcp/src/auth.rs`, middleware in `server.rs`.

## 5. PathPolicy (28 §3)

**Type:** `photonic_core::PathPolicy` (`crates/photonic-core/src/path_policy.rs`)  
**MCP helper:** `photonic_mcp::path_guard::check_path`

| Access | Default |
|--------|---------|
| Read | May leave roots if `allow_read_outside` (default **true**) |
| Write | Must stay under configured roots |

Desktop defaults roots: cwd, app config dir, `$HOME`.

### Handlers guarded (video branch)

| Tool | Access |
|------|--------|
| `save_document` | write |
| `import_media` | read |
| `export_sequence` | write |
| `relink_media` | read |
| `import_captions` | read |
| `export_captions` | write |
| `apply_lut` | read |
| `transcode_media` | write |

Denied paths return tool error text containing **`PathNotPermitted`** plus `error_code` / `reason` in data.

Main tree guards at least `save_document` (no video handlers).

## 6. Pattern B — large tool catalog

| Tool | Role |
|------|------|
| `search_actions` | Keyword search over name/description; slim schemas |
| `execute_action` | `{ "name", "arguments" }` → same as `tools/call` |

**Compact `tools/list` (default):** `search_actions`, `execute_action`, plus promoted tools that exist in the build (undo, screenshot, shapes, sequence/import/export when present).

**Full list:**

```json
{ "method": "tools/list", "params": { "full": true } }
```

or environment `PHOTONIC_MCP_FULL_TOOLS=1`.

Code: `crates/photonic-mcp/src/catalog.rs`.

### Live smoke (HTTP)

```bash
SECRET=$(openssl rand -hex 16)
PORT=17842
cargo run -p photonic-app -- --headless --mcp-port $PORT --mcp-secret "$SECRET" &
# discover, tools/list, tools/list full, search_actions, execute_action / tools/call
```

### Full catalog registration smoke

**Goal:** every name from full `tools/list` is dispatchable (not a full media/export success path).

```bash
# Server must already be running with Bearer secret
python3 tools/mcp_tool_smoke.py \
  --url http://127.0.0.1:$PORT/mcp \
  --token "$SECRET" \
  --timeout 8
```

| Outcome | Meaning |
|---------|---------|
| **REGISTERED** | Response is not `Unknown tool: <name>` (validation / domain errors OK) |
| **UNKNOWN** | Fail — name missing from dispatch |
| **TIMEOUT** | Investigate hangs (GPU/export); count separately |

**Pass criterion:** `unknown == 0`. Counts differ by tree (main ≈ vector-only; video ≈ vector+video).

**Headless note:** `screenshot` / `export_raster` may **timeout** without a full GPU capture path; that is not an unknown-tool failure. Tokio MCP workers use an **8 MiB** thread stack (`thread_stack_size`) so large `dispatch_tool_inner` / catalog paths do not overflow.
